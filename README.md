# Portfolio Projektów i Laboratoriów - Cyberbezpieczeństwo

W tym repozytorium znajdują się szczegółowe raporty i dokumentacje techniczne z zrealizowanych przeze mnie projektów z zakresu bezpieczeństwa sieciowego oraz systemów monitorowania.

## Zawartość repozytorium:

1. Projekt-koncowy2-wazuh (1).pdf
    **Opis:** Projekt wdrożenia systemu SIEM/XDR (Wazuh) w środowisku kontenerowym Docker oraz testy modułów FIM (File Integrity Monitoring) i automatycznej mitygacji ataków Brute Force (Active Response) za pomocą Kali Linux.

2. Projekt-Koncowy2.pdf
   **Opis:** Projekt bezpiecznej segmentacji sieci z podziałem na strefy WAN, LAN i odizolowaną strefę DMZ. Konfiguracja filtrów zapory sieciowej UFW (zasada Default Deny), routing, translacja adresów NAT/DNAT oraz hardening ruchu diagnostycznego ICMP.
